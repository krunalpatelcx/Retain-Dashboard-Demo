# RETAIN  Customer Success Retention Dashboard (Public Demo)

**A live-data, zero-cost retention dashboard built on top of a Google Sheet.**

This is a public, sanitized demo of a real Customer Success operations tool  a case-tracking system originally built for a multi-country CS team, then rebuilt for a SaaS retention use case. All data shown here is randomly generated and fictional. No real customer, account, or company information is included.

## The problem it solves

Most CS teams run on the same shared truth: a spreadsheet. But 20 agents filling a spreadsheet in 20 different formats produces data nobody can trust  half-filled fields, inconsistent labels, churn context that lives in someone's head instead of the record.

**RETAIN** pairs two things on top of one Google Sheet:
1. An **agent-facing form**  a simple, guided entry point where agents fill only the fields that matter, with validation on the ones that feed early-warning signals.
2. A **live dashboard**  reading the same sheet in real time, turning raw rows into retention KPIs, churn breakdowns, and risk flags without anyone building a chart by hand.

## What's in this demo

- `index.html`  the full dashboard UI (executive view, agent view, performance view), running in **local demo mode** with auto-generated mock case data.
- No backend required. No API keys. No cost. Open `index.html` in any browser, or visit the live GitHub Pages link below.

## Results from the real deployment

- 30% reduction in manual triage time
- 85–90% Net Revenue Retention on the accounts tracked through the system
- Real-time visibility replacing weekly manual chart-building in Sheets
